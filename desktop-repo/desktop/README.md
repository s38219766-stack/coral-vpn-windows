# Coral VPN для компьютера (консольная версия)

Работает на Linux и Windows. Внутри: `coral` (управление), `sing-box` (движок) и `ct` (наш протокол Coral Transport).

## Быстрый старт

1. Получите ссылку подписки в боте или в Mini App («Открыть в Coral» → «Копировать ссылку»).
2. Сохраните её:
   ```
   coral login <ссылка-подписки>
   ```
3. Подключитесь:
   - **Вся система** (нужны права администратора): Linux — `sudo ./coral up`, Windows — запустить командную строку «от имени администратора» и `coral up`.
   - **Без прав** (только программы, которые умеют работать через прокси): `coral up -mode proxy`. Прокси будет на `127.0.0.1:7890` (HTTP и SOCKS5).
4. Остановить: `Ctrl+C` в том же окне или `coral down` из другого.

## Команды

| Команда | Что делает |
|---|---|
| `coral login <ссылка>` | сохраняет подписку и проверяет её |
| `coral servers` | показывает способы подключения |
| `coral up [-mode tun\|proxy] [-route ru\|all] [-port 7890] [-server строка]` | подключается |
| `coral down` | отключает |
| `coral status` | состояние и проверка связи |

- `-route ru` (по умолчанию): российские сайты, банки и госсервисы идут напрямую, остальное через VPN. `-route all`: всё через VPN.
- `-server Coral FI` или `-server ct` или `-server hysteria2`: использовать только подходящие способы (удобно для проверки).
- По умолчанию подключается автоматически к самому быстрому способу и переключается, если он перестал отвечать.

## Файлы

Настройки лежат в `~/.config/coral` (Linux) или `%AppData%\coral` (Windows). Программы `sing-box` и `ct` должны быть рядом с `coral` (в архиве так и есть).

## Что пока не поддерживается

- XHTTP (запасной способ в подписке) на компьютере пропускается: движок его не умеет. Остальные способы работают.
- Иконка в трее и окно: пока только консоль.
